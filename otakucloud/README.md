# OtakuCloud
PHP 8+, PDO MySQL. Importar database/otakucloud_infinityfree.sql en una base vacía. Copiar config/local.example.php a config/local.php y ajustar datos privados. No publicar credenciales. En InfinityFree, subir solo index.php, acceso-admin.php, config y assets a htdocs. No subir database al directorio público.
